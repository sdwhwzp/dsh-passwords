## 接入的源码功能

- 聊天媒体（表情包/图片/视频）：`media_assets` / `message_media` 两张表、`allow_chat_media` 权限列、`/gateway/api/message-media/init|:id` 与带 `mediaIds` 的 `/gateway/api/messages`、媒体周期回收、删除用户时清理文件本体、权限卡片的「聊天媒体权限」勾选、`/api/dsh-passwords/state` 的 `mediaEnabled`。数据层按驱动分支：`INSERT OR IGNORE` / `INSERT IGNORE`、`LIMIT -1` / `LIMIT 18446744073709551615`、只在 SQLite 探测索引唯一性；其余方言由 `mysql-worker` 翻译。
- 端点登记表：`MCP_GATEWAY_SSH_ENDPOINTS`（`[owner:][ws:|http:]路径`）、`/gateway/api/overview` 的 `endpoints` / `pluginCompat`、`DSH_PASSWORDS_ENV_FILE` 下每 5 秒热更新并断开已授权 WS、已登记 HTTP 端点写请求的 `host` 私网判定。旧变量 `MCP_GATEWAY_SSH_WS_ENDPOINTS` 继续读取并按 `ws:` 规则并入，线上 `.env` 无需修改。
- 目录选择器删除按钮（`/gateway/api/fs/delete-directory`，仅主用户）与右侧栏文件下载按钮（复用 fork 已有的 `/gateway/api/download`，`state.fileDownload` 按 `allow_git_download` 判定）；两者的敏感目录基列表合并为 `sensitivePathBases()`。
- `app.set('trust proxy', 'loopback')`、根路径登录跳转不带 `next`、`patch` 子命令不再要求 `SETUP_KEY` 且补丁目标缺失以 35 退出、插件侧对 34/35/36 的启动错误提示、安装脚本的幂等重跑与自动装 Node/git/dsh（clone 地址保持 `sdwhwzp`）。

## 数据库变更（首次启动自动执行，幂等）

- `user_permissions` 新增列 `allow_chat_media`（SQLite `INTEGER NOT NULL DEFAULT 0`，MySQL `TINYINT NOT NULL DEFAULT 0`）：`migratePermissions()` 按列存在性 `ALTER TABLE … ADD COLUMN`，随后 `UPDATE … SET allow_chat_media = 0 WHERE allow_chat_media IS NULL`。
- 新表 `media_assets`、`message_media`：`CREATE TABLE IF NOT EXISTS`，MySQL 建表即带 `UNIQUE KEY idx_message_media_media (media_id)`；SQLite 另跑 `migrateMessageMediaUniqueness()`（表刚建时索引已唯一，直接返回）。
- 没有删除、重命名或改类型的操作；`ssh_host_owners`、`allowed_websocket_paths` 等旧列保留。
