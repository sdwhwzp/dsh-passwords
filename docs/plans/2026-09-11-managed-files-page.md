# 应用内文件夹管理与拖拽移动

文件夹管理在 Harness 的 main 槽中打开，保留侧栏和所选会话；“返回对话”选择原会话，不打开浏览器标签页。客户端必须声明 layout 依赖。入口仅在当前账号拥有专属文件夹时显示，文件操作继续使用逐次鉴权的 managed-files 接口。

文件或文件夹可拖到列表中的目标目录，或拖到“返回上级”按钮。拖拽仅接受当前面板登记的条目和一致的内部 MIME 数据；外部拖拽不能触发移动接口。目录不能拖到自身或子目录，忙碌/加载期间不允许开始移动。已有“移动/粘贴”按钮保留，供键盘及触摸操作使用。

移动沿用 from/toDirectory 接口及现有目录权限、符号链接和同名冲突检查。目标存在时显示错误；成功后刷新当前目录并显示结果。拖拽高亮仅用于表示有效目标，不改变服务器的授权判定。磁盘文件上传沿用上传控件。

“上传文件（可多选）”支持一次选择多个文件，按选择顺序上传到当前目录；页面显示当前文件、序号和总数。全部成功后显示上传数量并刷新列表；任一文件失败则停止后续上传，保留已上传的文件、显示已完成数量和错误，并刷新列表。上传期间禁用重复上传和目录导航，结束后重置选择框，允许再次选择同一批文件。“上传文件夹”继续保留相对目录层级。

验证包括面板内导航、外部载荷拒绝、文件移入目录、目录移到上一级、同目录/自身目标拒绝和同名冲突。线上验收使用唯一命名的临时目录与文件，复核内容后删除，不移动业务文件。
