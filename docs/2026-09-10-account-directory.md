# 独立账号管理页

管理员从侧栏「账号管理」或设置 → 密码门 →「打开账号管理页」进入 `/gateway/accounts`，也可以直接收藏该地址。该页面使用当前网关登录会话；未登录会跳转登录，普通账号无法访问页面或脚本。

列表支持用户名和 ID 搜索、角色及封禁状态筛选、账号名/最近登录/创建时间排序，以及每页 25、50、100 个账号。列中显示账号、角色、状态、月额度、本月已用和最近登录。新增账号、改名、改密及权限编辑在单账号对话框中完成；删除保留确认，未保存修改关闭前提示放弃。

设置页保留当前账号的个人信息与偏好，管理员目录转移到独立页面。权限字段和保存 API 沿用原实现，工作区、SSH、上传、下载、限额和封禁语义保持不变；打开目录不会创建账号或修改权限。

实现复用原账号编辑与权限草稿逻辑，仅挂载选中的编辑表单。页面每 30 秒刷新，未保存的权限草稿保留；列表在浏览器中分页，服务端仍返回完整账号目录，适合当前数百账号规模。月消费账本不可用时显示「—」，不将缺失消费显示为零。

验证：40 项相关客户端与网关测试通过；真实网关浏览器测试使用 206 个一次性账号，覆盖分页、搜索、封禁筛选、权限保存再读取、新建账号、单编辑器和手机宽度布局。桌面及手机截图、构建日志和部署记录留存在部署产物目录。
