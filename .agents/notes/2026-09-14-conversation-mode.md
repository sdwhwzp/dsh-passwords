# 会话权限与工作区归属分离

纯会话仍自动关联账号托管 Workspace，以满足 Harness 输入框和 Session 生命周期要求。不能把目录名、前端按钮状态或工作区有无当成纯会话权限依据。

服务端显示模式在 Session 发布前持久化，并随恢复与父会话分支继承。纯会话与开发模式共用账号工具权限；模式不能过滤模型工具列表、增加执行拒绝或跳过租户 shell 注册，否则会屏蔽 GenUI 校验，或让默认 shell 代替账号隔离的 shell。工具面板必须在聊天界面可见。

使用、备份要求与验证入口见 [纯会话模式](../../docs/2026-09-14-conversation-mode.md)。

原生 `sessions.refresh()` 复用正在进行的请求，其结果可能早于自定义创建 RPC。成功创建后用公开的 `sessions.create({ sessionId, cwd })` 幂等接入已创建会话并登记摘要，再打开会话；原生列表会将该变更重放到尚未完成的列表响应上。
